eda Module
==========

Run exploratory data analysis and persist lightweight profiles for train/test.

- **Depends on:** none
- **Key overrides:** ``eda.eda_notes="text"``
- **Outputs:** HTML/JSON profiles, summary JSON at ``experiments/eda/artifacts/eda/``, state at ``experiments/eda/state.json``

Source: ``src/mlarena/modules/eda.py``
