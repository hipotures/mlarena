┌─────────────────────────────────────────────────────────────────┐
│ KROK 2: MODEL (autogluon_boost_categorical.py)                  │
└─────────────────────────────────────────────────────────────────┘

2a. Czyta state.json:
   categorical_cols = _read_categorical_metadata(config, 'categorical_boost')
   # Returns: ['alcohol_consumption', 'family_history', ...]

2b. Weryfikuje dtype='category':
   if df[col].dtype != 'category':
       df[col] = df[col].astype('category')

2c. Konfiguruje feature generator:
   CategoryFeatureGenerator(
       cat_order='original',    # Zachowaj kolejność kategorii
       maximum_num_cat=None,    # Nie przycinaj kategorii
       minimum_cat_count=1,     # Nie łącz rzadkich kategorii
   )

2d. Konfiguruje hyperparameters dla boost algorytmów:
   'XGB': {
       'enable_categorical': True,  # ← KLUCZOWE dla XGBoost
       'tree_method': 'hist',       # Wymagane dla categorical
   },
   'GBM': {},  # LightGBM używa category natively
   'CAT': {},  # CatBoost używa category natively

┌─────────────────────────────────────────────────────────────────┐
│ KROK 3: BOOST ALGORITHMS (natywne wsparcie)                     │
└─────────────────────────────────────────────────────────────────┘

3a. XGBoost (enable_categorical=True):
   - Używa histogram-based tree method
   - Bezpośrednie split'y na kategoriach (nie one-hot!)
   - Obsługuje missing values w kategoriach
   
3b. LightGBM (automatyczne):
   - Wykrywa dtype='category'
   - Optimal split finding dla kategorii
   - Many-vs-many splits (nie tylko binary)
   
3c. CatBoost (automatyczne):
   - Target encoding na kategoriach
   - Obsługuje high-cardinality kategorii
   - Kombinacje kategorii (interactions)
